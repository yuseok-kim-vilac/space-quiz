# 우주 탐험 퀴즈

10개의 객관식 문제로 태양계와 우주에 관한 상식을 확인하는 한국어 웹 퀴즈입니다. 정답과 점수를 확인하고, 틀린 문제의 해설을 살펴볼 수 있습니다. 키보드의 `1`–`4` 키로 답을 고르고 Enter 키로 다음 문제로 진행할 수 있습니다.

## 로컬에서 실행하기

별도의 빌드 도구나 의존성은 필요하지 않습니다.

- `index.html`을 브라우저에서 직접 엽니다.
- 또는 저장소 루트에서 로컬 웹 서버를 실행합니다.

```bash
python -m http.server 8000
```

그런 다음 브라우저에서 <http://localhost:8000>을 엽니다.

## GitHub Pages 배포

`main` 브랜치에 변경 사항이 푸시되면 GitHub Actions가 `index.html`을 GitHub Pages에 배포합니다. 워크플로는 수동으로도 실행할 수 있습니다.
